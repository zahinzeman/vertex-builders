# Vertex Builders — Architecture & Commercial Construction

A modern single-page website for a tier-one construction & architecture enterprise, engineered with a strict sharp-cornered design system, rich micro-interactions, Lenis smooth scrolling, GSAP ScrollTrigger reveals, dynamic counters, and live Supabase lead capture.

---

## 🏛️ Brand & Identity

- **Brand Name**: VERTEX BUILDERS
- **Founded**: 2015
- **Headquarters**: 742 Montgomery St, San Francisco, CA 94111
- **Focus**: Commercial towers, seismic structural engineering, mass timber, and residential landmarks.

---

## 📐 Design Tokens & Architecture

- **Color Palette**:
  - `ink`: `#161616` (Dark sections: Projects, Testimonials, Footer)
  - `mint`: `#DEEDDD` (Tinted sections: Services, Contact, subtle accents)
  - `white`: `#FFFFFF` (Light sections: About, Commitment, News, FAQ)
  - `body`: `#555555`
  - `muted`: `#969696`
  - `line`: `#DCDCDC`
  - `line_dark`: `rgba(255, 255, 255, 0.15)`
- **Corner Radius**: `0px` sharp corners everywhere (buttons, cards, images, inputs); only circular elements are avatars (100px) and the mint icon dots (60px).
- **Typography**: `Onest` (weights 400, 500, 600) via Google Fonts.
- **Reference Viewport**: 1440px desktop with centered 1296px content container (20px gutters, 1336px outer).

## ⚡ Interactive Features

1. **Lenis Smooth Scroll** with GSAP 3 ScrollTrigger integration.
2. **Dynamic Header Navigation**:
   - Transparent overlay nav at top of hero.
   - Sticky fixed navbar sliding in after hero with auto-hide on scroll down and reveal on scroll up.
   - Interactive dropdown for *Resources* and text-roll hover animation on all primary actions.
3. **Hero Section**:
   - Cinematic wide construction visual with play/pause toggle.
   - Live CountUp animated stat cards (`08+`, `25+`).
4. **Interactive Component Architecture**:
   - `IconWithDot` feature badges with animated scale reveals.
   - Hover zoom with centered arrow scale badge on project cards.
   - Sticky dual-column layouts on Services and FAQ.
   - Testimonial carousel with progress timing bar and prev/next controls.
   - Single-open accessible FAQ accordion.
   - Fullscreen mobile drawer with accordion navigation.
   - Back-to-top button appearing after 1200px scroll.

### Database Schema Migration
Run the following SQL in your Supabase SQL editor (`supabase-schema.sql`):
```sql
create table if not exists public.contact_submissions (
    id bigint generated by default as identity primary key,
    first_name text not null,
    last_name text not null,
    email text not null,
    phone text,
    message text not null,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

alter table public.contact_submissions enable row level security;

create policy "Allow public anonymous submissions"
    on public.contact_submissions
    for insert to anon with check (true);
```
